1. FONTS (TYPOGRAPHY)
================================================================================

Primary Fonts:
--------------
• Outfit    - Used for Headings (h1-h6)
              Weights: 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold)
              
• Inter     - Used for Body text
              Weights: 400 (Regular), 500 (Medium)

CSS Usage:
----------
font-family: 'Outfit', sans-serif;    /* Headings */
font-family: 'Inter', sans-serif;     /* Body text */

Tailwind Classes:
-----------------
className="font-heading"    /* Uses Outfit */
className="font-body"       /* Uses Inter */
className="font-sans"       /* Uses Inter (default) */

6. ANIMATIONS & KEYFRAMES
================================================================================

FADE IN:
--------
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to   { opacity: 1; transform: translateY(0); }
}
Class: .animate-fade-in (0.5s ease-out)

SLIDE DOWN:
-----------
@keyframes slideDown {
  from { opacity: 0; transform: translateY(-8px); }
  to   { opacity: 1; transform: translateY(0); }
}
Class: .animate-slide-down (0.2s ease-out)

TICKER SCROLL:
--------------
@keyframes ticker {
  0%   { transform: translateX(0); }
  100% { transform: translateX(-50%); }
}
Class: .ticker-scroll (40s linear infinite)
       Pauses on hover

ACCORDION:
----------
accordion-down: Height 0 → auto (0.2s)
accordion-up:   Height auto → 0 (0.2s)
